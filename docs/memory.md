# Memory Architecture

## 1. Общая организация памяти

В архитектуре используется **Гарвардская организация памяти (Harvard Architecture)**.

Процессор использует два независимых адресных пространства:

- **Instruction Memory (IMEM)** — хранение машинного кода и таблицы векторов прерываний.
- **Data Memory (DMEM)** — хранение данных программы, строковых констант, глобальных переменных, стека, кучи и регистров устройств ввода-вывода (MMIO).

### 1.1. Основные характеристики

| Характеристика | Значение |
|---|---|
| Организация памяти | Harvard |
| Разрядность машинного слова | 32 бита |
| Разрядность адреса | 32 бита |
| Разрядность инструкции | 32 бита |
| Адресуемая единица | 1 байт |
| Endianness | Little-endian |
| Instruction Memory | \(2^{16}\) байт |
| Data Memory address space | \(2^{32}\) байт |
| Модель Data Memory | Sparse Memory |

---

## 2. Instruction Memory

Instruction Memory предназначена для хранения машинных инструкций и таблицы векторов прерываний.

### 2.1. Основные характеристики

| Характеристика | Значение |
|---|---|
| Размер | \(2^{16}\) байт |
| Разрядность адреса | 16 бит |
| Разрядность инструкции | 32 бита |
| Адресация | Byte-addressable |
| Endianness | Little-endian |

Каждая инструкция занимает 4 байта. Адрес инструкции должен быть выровнен по границе 4 байт.

### 2.2. Карта Instruction Memory

| Адрес | Назначение |
|---|---|
| `0x0000` | Reset vector |
| `0x0004` | Input interrupt vector |
| `0x0008` | Reserved |
| `0x000C` | Начало секции `.text` |

---

## 3. Data Memory

### 3.1. Основные характеристики

| Характеристика | Значение |
|---|---|
| Разрядность адреса | 32 бита |
| Размер адресного пространства | \(2^{32}\) байт |
| Адресация | Byte-addressable |
| Endianness | Little-endian |
| Модель реализации | Sparse Memory |

### 3.2. Карта Data Memory

| Область | Начальный адрес | Конечный адрес | Назначение |
|---|---|---|---|
| MMIO | `0x00000000` | `0x0000000F` | Регистры устройств |
| Reserved | `0x00000010` | `0x00000FFF` | Зарезервированная область |
| `.rodata` | `0x00001000` | `0x00001FFF` | Константные данные |
| `.data` | `0x00002000` | `0x00002FFF` | Инициализированные данные |
| `.bss` | `0x00003000` | `0x00003FFF` | Неинициализированные данные |
| Heap | `0x00004000` | `0xBFFFFFFF` | Динамическая память |
| Reserved | `0xC0000000` | `0xFFEFFFFF` | Зарезервированная область |
| Stack | `0xFFF00000` | `0xFFFFFFFF` | Стек программы |

Heap растёт в сторону увеличения адресов.

Stack растёт в сторону уменьшения адресов.

При пересечении границ Heap и Stack возникает ошибка переполнения памяти.

### 3.3. Стек

Стек используется для хранения:

- адресов возврата;
- локальных переменных;
- сохранённых регистров;
- аргументов функций;
- временных данных.

Стек растёт вниз, в сторону меньших адресов.

## 4. Memory-Mapped I/O

Ввод-вывод реализован через Memory-Mapped I/O(по варианту)

### 4.1. Карта MMIO

| Адрес | Имя | Назначение |
|---|---|---|
| `0x00000000` | `INPUT_DATA` | Регистр входных данных |
| `0x00000004` | `OUTPUT_DATA` | Регистр выходных данных |
| `0x00000008` | `CYCLE_COUNTER` | Счётчик тактов процессора |
| `0x0000000C` | `INPUT_STATUS` | Состояние устройства ввода |

### 4.2. Ввод данных

Устройство ввода предоставляет процессору байты через регистр `INPUT_DATA`.

### 4.3. Вывод данных

Для вывода символа процессор записывает его значение в `OUTPUT_DATA`.

### 4.4. Счётчик тактов

`CYCLE_COUNTER` предоставляет доступ к текущему количеству тактов процессора.

### 4.5. Обработка MMIO

Доступ к MMIO обрабатывается адресным декодером памяти.

MMIO не кэшируется.

---

## 5. Представление данных

Память является байтово-адресуемой.

Многобайтовые значения хранятся в формате Little-endian: младший байт располагается по младшему адресу.

### 5.1. Доступ к памяти

| Инструкция | Размер доступа | Поведение |
|---|---:|---|
| `LOAD` | 4 байта | Чтение 32-битного слова |
| `LOADB` | 1 байт | Чтение байта с расширением нулями |
| `STORE` | 4 байта | Запись 32-битного слова |
| `STOREB` | 1 байт | Запись младших 8 бит регистра |

### 5.2. C-строки

Для представления строк используется формат C-string.

Строка представляет собой последовательность байтов, заканчивающуюся нулевым байтом (`0x00`).

Статические строковые константы размещаются в секции `.rodata`.

---

## 6. Cache

Для ускорения доступа к Data Memory используется кэш данных(по варианту)

### 6.1. Временные характеристики (по варианту)

| Операция | Количество тактов |
|---|---:|
| Cache hit | 1 |
| Cache miss | 10 |

При Cache hit данные возвращаются из кэша за один такт.

При Cache miss процессор ожидает завершения обращения к основной памяти.

### 6.2. Особенности работы

- Кэш применяется к обычной Data Memory.
- MMIO-адреса обходят кэш.
- Cache hit и Cache miss фиксируются в журнале выполнения.
- Ожидание завершения обращения к основной памяти отражается в тактовой модели процессора.
