# DataPath Architecture

## 1. Общая структура

Основные компоненты DataPath:

- Program Counter (PC);
- Instruction Register (IR);
- Register File (16 регистров общего назначения);
- Arithmetic Logic Unit (ALU);
- Address Register (AR);
- Write Register (WR);
- Immediate Generator (ImmGen);
- мультиплексоры;
- сумматоры;
- Cache;
- Address Decoder;
- Load Unit;
- Instruction Memory;
- Data Memory;
- устройства ввода-вывода (MMIO);
- Exception Program Counter (EPC).

### 1.1. Основные характеристики

| Характеристика | Значение |
|---|---|
| Разрядность процессора | 32 бита |
| Разрядность регистров | 32 бита |
| Количество регистров общего назначения | 16 |
| Разрядность инструкции | 32 бита |
| Размер инструкции | 4 байта |
| Организация памяти | Harvard |
| Endianness | Little-endian |
| Адресация памяти | Byte-addressable |

## 2. Регистры процессора

### 2.1. Program Counter (PC)

PC хранит адрес текущей инструкции в Instruction Memory.

На каждом цикле выполнения процессор определяет адрес следующей инструкции.

Возможные трактоыки:

| Источник | Назначение |
|---|---|
| `PC + 4` | Последовательное выполнение |
| `PC + 4 + offset` | Условный или безусловный переход |
| `EPC` | Возврат после прерывания |
| `handler_address` | Переход к обработчику прерывания |

### 2.2. Instruction Register (IR)

IR хранит текущую 32-битную инструкцию, полученную из Instruction Memory.

Поля инструкции используются для управления Register File, ImmGen и декодером инструкций.

### 2.3. Register File

Register File содержит 16 регистров общего назначения:

\[
R0, R1, \ldots, R15
\]

Каждый регистр имеет разрядность 32 бита.

Register File обеспечивает чтение двух операндов и запись результата операции.

Основные сигналы:

| Сигнал | Назначение |
|---|---|
| `rs1` | Выбор первого регистра для чтения |
| `rs2` | Выбор второго регистра для чтения |
| `rd` | Выбор регистра для записи |
| `we_reg` | Разрешение записи в регистровый файл |

Подробнее описано в isa_docs.md

### 2.4. Address Register (AR)

AR хранит адрес обращения к Data Memory.

Перед выполнением операции чтения или записи адрес формируется в ALU и сохраняется в AR.

AR передаёт адрес в Address Decoder, который определяет назначение обращения.

### 2.5. Write Register (WR)

WR является промежуточным регистром для хранения данных, полученных в результате операции чтения памяти.

### 2.6. Exception Program Counter (EPC)

EPC хранит адрес возврата при обработке прерывания.

## 3. Program Counter datapath

Для формирования следующего значения PC используются два сумматора и мультиплексор.

### 3.1. Инкремент PC

\[
PC_{next} = PC + 4
\]

### 3.2. Вычисление адреса перехода

\[
PC_{target} = PC + 4 + offset
\]

### 3.3. Выбор следующего адреса

| Источник | Условие использования |
|---|---|
| `PC + 4` | Обычное выполнение инструкции |
| `PC + 4 + offset` | Выполнение перехода |
| `EPC` | Выполнение `IRET` |
| `handler_address` | Принятие прерывания |

---

## 4. Arithmetic Logic Unit (ALU)

ALU выполняет арифметические и логические операции над 32-битными операндами.

### 4.1. Выбор второго операнда

MUX B выбирает один из двух источников:

1. Значение второго регистра `rs2`.
2. Непосредственное значение `imm`, сформированное ImmGen.

### 4.2. Поддерживаемые операции

| Группа | Операции |
|---|---|
| Арифметические | ADD, SUB, MUL, DIV |
| Логические | AND, OR, XOR, NOT |
| Сдвиги | SHL, SHR |
| Сравнения | SLT, SLTU |

### 4.3. Условия переходов

ALU формирует результат сравнения операндов.

## 5. Memory datapath

Доступ к Data Memory осуществляется через AR, Address Decoder и Cache.

### 5.1. Address Register

Перед обращением к памяти эффективный адрес вычисляется ALU:

\[
address = base + offset
\]

Полученное значение сохраняется в AR.

### 5.2. Address Decoder

Address Decoder определяет, к какой области Data Memory относится обращение.

## 6. Memory-Mapped I/O

Устройства ввода-вывода отображаются в адресное пространство Data Memory.

В архитектуре используются следующие регистры:

| Адрес | Устройство | Назначение |
|---|---|---|
| `0x00000000` | Input Port | Входные данные |
| `0x00000004` | Output Port | Выходные данные |
| `0x00000008` | Cycle Counter | Счётчик тактов |
| `0x0000000C` | Input Status | Состояние входного устройства |
