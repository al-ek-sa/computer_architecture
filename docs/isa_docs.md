Размер инструкций -- 32 бита. Код операции занимает начальные позиции инструкции, остальные биты используются для кодирования операндов и непосредственных значений.

## 1. Форматы инструкций

В архитектуре предусмотрено шесть форматов инструкций:

| Формат | Назначение |
|---|---|
| R | Регистровые операции |
| I | Операции с непосредственными значениями и загрузкой из памяти |
| S | Операции записи в память |
| B | Условные переходы |
| U | Работа с верхней частью непосредственного значения |
| J | Безусловные переходы и вызовы процедур |

## 2. Система команд

Вся система команд разделена по логическому использованию и роду команд, у всех блоков есть отличие это 0хN*, в котором N является индентификатором блока. В каждом блоке есть зарезервированные коды операций.

### 2.1. Арифметические и логические инструкции

| Opcode | Инструкция | Формат | Описание |
|---:|---|---|---|
| 0x00 | NOP | R | Отсутствие операции |
| 0x01 | ADD | R | Сложение |
| 0x02 | SUB | R | Вычитание |
| 0x03 | MUL | R | Умножение |
| 0x04 | DIV | R | Деление |
| 0x05 | AND | R | Побитовое И |
| 0x06 | OR | R | Побитовое ИЛИ |
| 0x07 | XOR | R | Побитовое исключающее ИЛИ |
| 0x08 | NOT | R | Побитовое отрицание |
| 0x09 | SHL | R | Логический сдвиг влево |
| 0x0A | SHR | R | Логический сдвиг вправо |
| 0x0B–0x0F | RESERVED | — | Зарезервированные коды |

### 2.2. Инструкции непосредственных значений и работы с памятью

| Opcode | Инструкция | Формат | Описание |
|---:|---|---|---|
| 0x10 | ADDI | I | Сложение регистра с непосредственным значением |
| 0x11 | MOVI | I | Загрузка непосредственного значения в регистр |
| 0x12 | LUI | U | Загрузка непосредственного значения в старшие биты |
| 0x13 | ORI | I | Побитовое ИЛИ с непосредственным значением |
| 0x14 | LOAD | I | Загрузка 32-битного слова из памяти |
| 0x15 | LOADB | I | Загрузка байта из памяти |
| 0x16 | STORE | S | Запись 32-битного слова в память |
| 0x17 | STOREB | S | Запись байта в память |
| 0x18–0x1F | RESERVED | — | Зарезервированные коды |

### 2.3. Инструкции сравнений и условных переходов

| Opcode | Инструкция | Формат | Описание |
|---:|---|---|---|
| 0x20 | BEQ | B | Переход при равенстве |
| 0x21 | BNE | B | Переход при неравенстве |
| 0x22 | BLT | B | Переход, если первое значение меньше второго |
| 0x23 | BGE | B | Переход, если первое значение больше или равно второму |
| 0x24 | SLT | R | Установка результата сравнения (signed) |
| 0x25 | SLTU | R | Установка результата сравнения (unsigned) |
| 0x26–0x2F | RESERVED | — | Зарезервированные коды |

### 2.4. Инструкции управления потоком исполнения

| Opcode | Инструкция | Формат | Описание |
|---:|---|---|---|
| 0x30 | JMP | J | Безусловный переход |
| 0x31 | CALL | J | Вызов процедуры |
| 0x32 | RET | R | Возврат из процедуры |
| 0x33 | IRET | R | Возврат из обработчика прерывания |
| 0x34 | HALT | R | Остановка процессора |
| 0x35–0x3F | RESERVED | — | Зарезервированные коды |

## 3. Форматы инструкций

Итоговая таблица, которая показывает какие инструкции относятся к какому формату.

| Формат | Назначение | Инструкции |
|---|---|---|
| R | Операции над регистрами и управление исполнением | NOP, ADD, SUB, MUL, DIV, AND, OR, XOR, NOT, SHL, SHR, SLT, SLTU, RET, IRET, HALT |
| I | Операции с непосредственными значениями и загрузка из памяти | ADDI, MOVI, ORI, LOAD, LOADB |
| S | Запись данных в память | STORE, STOREB |
| B | Условные переходы | BEQ, BNE, BLT, BGE |
| U | Загрузка непосредственного значения в старшую часть регистра | LUI |
| J | Безусловные переходы и вызовы процедур | JMP, CALL |

## 4. Регистровая модель

Архитектура использует 16 регистров общего назначения размером 32 бита. Регистровая модель основана на RV32E.

Регистры общего назначения обозначаются `R0–R15`.

| Индекс | Имя | Назначение |
|---:|---|---|
| R0 | ZERO | Всегда содержит ноль. Запись в регистр игнорируется |
| R1–R4 | — | Регистры общего назначения |
| R5–R7 | — | Регистры общего назначения |
| R8–R13 | — | Регистры общего назначения |
| R14 | SP | Указатель стека (Stack Pointer) |
| R15 | RA | Адрес возврата из процедуры (Return Address) |

Регистр `R0` является константным: при чтении всегда возвращает нулевое значение, а операции записи в него не изменяют его содержимое.

Регистры `R1–R13` могут использоваться для хранения операндов, промежуточных результатов и локальных данных. Их назначение определяется соглашениями программы.

`R14 (SP)` используется для адресации стека. Стек растёт в сторону уменьшения адресов.

`R15 (RA)` хранит адрес возврата после выполнения инструкции `CALL`. Инструкция `RET` использует значение данного регистра для восстановления потока исполнения.

Помимо регистров общего назначения, процессор содержит специализированные регистры управления:

| Регистр | Размер | Назначение |
|---|---:|---|
| PC | 32 бита | Счётчик команд, содержит адрес следующей инструкции |
| IR | 32 бита | Регистр текущей инструкции |
| EPC | 32 бита | Сохраняет адрес возврата при обработке прерывания |
| AR | 32 бита | Регистр адреса памяти |

Специализированные регистры не входят в набор регистров общего назначения и не адресуются инструкциями обычной арифметики.
